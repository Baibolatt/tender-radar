# Цветочный бот и панель заказов (Тараз)

Telegram-бот принимает заказы на цветы, веб-панель показывает их флористу в реальном времени.

## Бот

Принимает заказ (букет, дата, адрес, открытка), присваивает номер и шлёт уведомление флористу. Подробности — в `CLAUDE.md`.

```bash
.venv/bin/python -m bot.main
```

Токен и ключ ИИ — в `.env` (см. `.env.example`).

## WhatsApp Webhook Setup

Вебхук WhatsApp Cloud API запускается отдельным процессом на порту 8080 и использует ту же базу, что и бот.

```bash
.venv/bin/python -m bot.run_web
```

### В Codespaces

1. Запустите вебхук: `.venv/bin/python -m bot.run_web`.
2. На вкладке **Ports** найдите порт `8080` и сделайте его **Public**.
3. Скопируйте публичный URL порта, например `https://xxx-8080.app.github.dev`.
4. В Meta Developer Console → WhatsApp → Configuration → Webhook укажите:
   - **Callback URL:** `https://xxx-8080.app.github.dev/webhook`
   - **Verify Token:** значение `WEBHOOK_VERIFY_TOKEN` из `.env`
   - **Subscribe to:** `messages`

Токен хранится только в переменных окружения (`.env`), в репозиторий его не коммитят.

## Панель заказов флориста

Веб-панель на aiohttp: флорист видит заказы, меняет статус одной кнопкой, ищет по имени/телефону и фильтрует по статусу. Новые заказы появляются мгновенно — со звуком и подсветкой.

```bash
.venv/bin/python -m web
```

Настройки в `.env`:

- `PANEL_PASSWORD` — пароль входа (обязательно).
- `PANEL_HOST` — адрес (по умолчанию `127.0.0.1`).
- `PANEL_PORT` — порт (по умолчанию `8000`).

Панель читает ту же базу (`DATABASE_PATH`), что и бот, поэтому оба процесса можно запускать одновременно.

### Статусы заказа

Статусы задаются в одном месте — `web/statuses.py`. Чтобы добавить или переименовать статус, отредактируйте список `STATUSES` (ключ, русская подпись, `next_action` — подпись кнопки перехода). Панель подхватит изменения без правок фронтенда.

### Обновление в реальном времени

Панель открывает SSE-поток `/api/events`: сервер раз в ~1.5 секунды сверяет отпечаток таблицы заказов и при изменении шлёт сигнал — браузер перечитывает список.
