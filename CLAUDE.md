# О проекте

Мы создаём B2B SaaS: AI-менеджера для цветочных магазинов в Таразе (Казахстан). Бот отвечает клиентам вместо менеджера, быстро и круглосуточно. Он показывает каталог и цены, уточняет дату, адрес и открытку, принимает заказ с уникальным номером и передаёт заявку флористу. Если клиент злится или просит нестандартное, бот зовёт живого человека. Магазины платят ежемесячную подписку.

# Текущий этап

Пробная версия: Телеграм-бот + WhatsApp (второй канал, официальный Cloud API), каталог на 10-20 букетов, приём заказа с номером, уведомление флористу. Без оплаты и без Instagram. Позже: оплата через Kaspi или банк, Instagram Direct, вызов курьера, очередь заказов.

# Правила работы

1. Всегда отвечай мне только по-русски: объяснения, планы, вопросы. Код, имена переменных и коммиты пиши на английском, комментарии в коде — по-русски.
2. Сначала составляй план и жди моего «да», потом пиши код.
3. Делай маленькие шаги и объясняй просто — я работаю с iPad.
4. Не клади API-ключи и токены в файлы, только в переменные окружения.
5. Следи за расходом токенов API, не делай лишних вызовов модели.

# Экономия денег и токенов

6. По умолчанию работай САМ (inline), не запускай субагентов — они дорогие. Субагент — только для реально независимой работы, которую можно делать параллельно, или по моей явной просьбе. Один финальный ревью в конце вместо ревью на каждый шаг.
7. Если субагент всё же нужен — бери самую дешёвую подходящую модель: haiku для механических задач, sonnet для средних, opus только для архитектуры и финального ревью всей ветки.
8. Не перечитывай большие файлы целиком — читай только нужные куски (offset/limit) и по назначению.
9. Не переспрашивай по мелочам: если решение очевидное и обратимое — прими его, коротко скажи о нём и продолжай. Останавливайся только перед необратимым, секретным или внешним действием (push, PR, публикация, удаление).

# Как запускать

- Бот (Telegram + уведомления флористу): `.venv/bin/python -m bot.main`
- Вебхук WhatsApp (порт 8080): `.venv/bin/python -m bot.run_web` — для работы обоих держать запущенными одновременно.
- Тесты: `.venv/bin/python -m pytest tests/ -q`
